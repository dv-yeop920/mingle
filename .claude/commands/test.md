# /test — 테스트 실행

## 워크플로우

### Step 1: 변경사항 파악
- `git diff --name-only`로 변경된 파일 목록 확인
- 변경사항이 없으면 중단

### Step 2: Test 에이전트 호출
- `.claude/agents/test.md`의 Test 에이전트를 호출한다
- 변경된 파일 목록을 전달한다

### Step 3: 테스트 실행
- 변경된 파일에 대응하는 `.test.ts` / `.test.tsx` 파일이 있으면 실행
- 대응 테스트가 없으면 Test 에이전트에게 작성을 요청
- `npm run test -- <테스트 파일 경로>`로 개별 실행

### Step 4: 결과 보고
```
## 테스트 결과

- 실행: N개 파일
- 통과: N개 / 실패: N개
- 실패 상세: (있으면 파일별 에러 내용)
```

### Step 5: 실패 시
- 실패 내용을 분석하여 수정 담당 에이전트를 제안
- 사용자에게 수정 여부를 확인한다
