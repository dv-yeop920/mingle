# /review — 코드 리뷰 실행

## 워크플로우

### Step 1: 변경사항 파악
- `git diff --name-only`로 변경된 파일 목록 확인
- `git diff --staged --name-only`로 staged 파일도 확인
- 변경사항이 없으면 중단

### Step 2: Review 에이전트 호출
- `.claude/agents/review.md`의 Review 에이전트를 호출한다
- 변경된 파일 목록을 전달한다

### Step 3: 결과 보고
아래 형식으로 보고한다:

```
## 점검 결과

### ✅ 통과
- (통과 항목 요약)

### ❌ 위반
1. **[보안/정확성/컨벤션]** `파일경로:라인` — 위반 내용
   → 수정 담당: ui / frontend / backend
   → 수정 방법: (구체적 수정 지침)
```

### Step 4: 위반 사항이 있으면
- 심각도별로 정렬 (보안 > 정확성 > 컨벤션)
- 각 위반에 대해 수정 담당 에이전트를 명시
- 사용자에게 수정 여부를 확인한다
